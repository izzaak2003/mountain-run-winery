# Mountain Run Winery working guidance

This repository is an unofficial portfolio concept. Keep that disclosure visible
on every page. The parent project's synced reference files are read-only.

## Scope and workflow

- Astro + TypeScript + plain CSS. No React, Tailwind, or CMS for this version.
- Ship small, useful changes through GitHub to the existing free Netlify site.
- Explain important steps plainly for a frontend beginner on Windows. Make direct
  recommendations and avoid scope creep.
- No homelab or model-hosting work. A future concierge can call an external model
  through a server-side function; never put API secrets in browser code.
- Purchases, reservations, and inquiries go to official winery services.
- Verify changing business details against official sources, record the source
  and review date, and label snapshots honestly.

## Design and voice — user's updated direction, September 17, 2026

- Derive the design from this particular farm: its corn crib, slatted walls,
  agricultural history, Culpeper location, real photographs, and playful wine names.
- Keep the earthy palette and intentional Fraunces / Source Sans 3 pairing.
  Each future client needs their own typography, palette, and layout.
- Avoid startup gradients, default sans-only typography, generic centered heroes,
  identical rounded cards, shadow-heavy icon grids, glass effects, generic line
  icons or emoji section markers, blob illustrations, and placeless imagery.
- Use editorial hierarchy and purposeful asymmetry, not symmetry by default.
- Avoid empty superlatives, vague benefits, repeated three-part slogans, question
  headlines, motivational filler, and "not just X, it's Y" copy.
- Avoid filler such as "elevate", "unlock", "seamless", "effortless", and generic
  buttons such as "Get Started" or "Learn More". Name the action or destination.
- Write like a person familiar with the business. Support factual claims with
  names, places, numbers, or actual stories; do not invent experiences or facts.
- Before publishing, ask whether the design/copy could be swapped onto another
  business unnoticed, and whether generic AI habits remain. Rework those parts.
- The barn mark is an accepted placeholder. Refine it later, without blocking
  useful pages or the deployment workflow.

Run the existing build check and inspect changed pages at desktop and phone
widths, including navigation and keyboard behavior, before publishing.
